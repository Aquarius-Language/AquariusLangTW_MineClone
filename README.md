# 星泉無垠 · AquaCraft

**星泉無垠** (English name: AquaCraft) is a Minecraft-inspired voxel survival sandbox written in **AquariusLang (星泉)** on top of the language's
low-level **WGPU** module. The same compiled `aquacraft.wasm` runs on the desktop (wgpu-native
through the Aquarius desktop host) and in the browser (WebGPU). All textures, sounds, the Latin
pixel font and the UI are original and generated by the scripts in `tools/`; Chinese text uses the
Cubic 11 pixel font (see Language).

The interface is in **繁體中文** by default and can be switched to **English** at any time.

## Requirements

- An AquariusLang checkout that includes the WGPU window/input extension
  (`CreateWindow`, `CreateDevice(window)`, storage buffers, `SetState`, `DrawProcedural`,
  `Present`). It lives on the `feature/wgpu-window-input` branch of `AquariusLangTW`.
- .NET 8 SDK (to build the `aqua` CLI), Windows/macOS/Linux with a Vulkan, Metal or D3D12 GPU.
- For the web build: a WebGPU browser (Chrome/Edge 113+, Safari 18+, Firefox 141+ on Windows).
- Python 3 with NumPy and Pillow only if you want to regenerate the assets.

## Build and run

```bat
rem 1. Build the Aquarius CLI once (from the AquariusLangTW checkout)
cd C:\path\to\AquariusLangTW
dotnet build AquariusCli -c Release
set AQ=C:\path\to\AquariusLangTW\AquariusCli\bin\Release\net8.0\aqua.exe

rem 2. Build the game (portable .wasm + static website)
cd C:\path\to\AquariusLangTW_MineClone
tools\build.cmd web

rem 3a. Desktop
"%AQ%" run build\aquacraft.wasm

rem 3b. Browser: serve build\web over http and open it
python -m http.server 8765 -d build\web
rem then open http://localhost:8765/
```

On macOS/Linux run the same `aqua build …` command that `tools/build.cmd` contains.
`tools\build.cmd web exe` also writes a standalone `build\AquaCraft.exe`. The Windows runtime
pack must include the new desktop host, so publish it once from the AquariusLangTW checkout and
point the CLI at it:

```bat
powershell -ExecutionPolicy Bypass -File scripts\publish-apphost.ps1
set AQUARIUS_BUILD_TARGETS=C:\path\to\AquariusLangTW\build-targets
tools\build.cmd web exe
```

Regenerate assets (optional): `python tools/gen_textures.py`, `python tools/gen_font.py`,
`python tools/gen_sounds.py`. Re-run `gen_font.py` whenever you add Chinese text (see Language).

## Controls

| Input | Action |
| --- | --- |
| W A S D | Move |
| Mouse | Look (pointer lock; click the window if it is released) |
| Space | Jump / swim up |
| Shift | Sprint |
| Hold left click | Mine the targeted block (cracks and a progress bar show how far along it is) / attack a creature |
| Right click | Place the selected block, or open a crafting table, furnace or chest |
| 1–9, mouse wheel | Select hotbar slot |
| E | Open / close the inventory (2x2 crafting grid and recipe guide) |
| Q (Ctrl+Q) | Drop one item (the whole stack) |
| Esc | Close a screen / pause menu (Resume, Settings, Save & Title) |
| F3 | Toggle FPS / chunk / position display |

Inside an inventory, crafting table, chest or furnace screen:

| Input | Action |
| --- | --- |
| Left click | Pick up a stack / put it down / merge / swap |
| Left drag | Drag a stack onto another slot and release (drag-and-drop) |
| Right click | Take half a stack, or place a single item |
| Right drag | Spread single items over every slot you pass |
| Shift + click | Quick transfer (hotbar ↔ backpack, inventory ↔ chest, ore/fuel → furnace, craft output → as many as fit) |
| 1–9 over a slot | Swap that slot with a hotbar slot |
| Q over a slot | Drop one item |
| Click outside the panels | Throw the stack on the cursor |
| Recipe guide icon | Hover for ingredients; click a green (craftable) recipe to lay it out in the grid |

Settings (title screen or pause menu): graphics preset (Low/Medium/High/Ultra), render
distance, shadow quality, effects (bloom + water reflections), render scale, mouse
sensitivity, field of view, master volume, night creatures on/off, the FPS display and the
interface language.

## Language / 介面語言

- The game starts in **繁體中文** (window and page title 星泉無垠). Switch with the
  **English / 繁體中文** button at the top right of the title screen, or with **語言 / Language**
  at the top of Settings. The choice is saved with the settings; English shows the name AquaCraft.
- Every UI string is keyed by its English text in `src/lang.aqua`; the UI translates at draw
  time, so menus, settings, HUD messages, item and block names, tooltips, the recipe guide
  and the container screens all follow the switch immediately. Sentences with values use
  `{0}` templates (for example `"{0} broke!"` → `"{0}壞掉了！"`).
- Chinese glyphs come from **Cubic 11 (俐方體11號)**, an open-source Traditional Chinese pixel
  font (SIL Open Font License, `tools/fonts/`). `tools/gen_font.py` renders only the characters
  that appear in the game's strings (currently 237) at the font's native 12 px into the UI
  atlas next to the Latin glyphs and writes the lookup table to `src/glyphs.aqua`. Chinese
  glyphs are 11x11 pixels and advance 12; lines are spaced wider in Chinese.

## Survival gameplay

- **Inventory**: 27 backpack slots plus the 9-slot hotbar; stacks of 64 (tools do not stack).
  Every broken block drops its item, nearby drops fly into the inventory when there is room,
  and placing a block uses one item from the selected stack.
- **Mining**: blocks have hardness; holding the mouse button builds up cracks over ten stages.
  Mining time is `hardness × 1.5 ÷ tool speed` (`× 5` when the block needs a better tool).
  Stone, cobblestone, coal ore and furnaces need a pickaxe to drop anything; iron ore needs a
  stone pickaxe or better. Grass drops dirt, stone drops cobblestone, coal ore drops coal and
  leaves sometimes drop sticks.
- **Tools**: pickaxes, axes, shovels and swords in wood, stone and iron (speeds 2/4/6,
  durability 59/131/250). Durability bars appear on worn tools; a tool that wears out breaks
  with a sound and a message.
- **Crafting**: a reusable recipe system with shaped (mirrorable) and shapeless recipes. The
  inventory has a 2x2 grid, a placed crafting table a 3x3 grid. Ingredients are only consumed
  when you take the output. Recipes: planks (shapeless, from a log), sticks, crafting table,
  torches, furnace, chest and every tool tier.
- **Furnace**: put ore in the top slot and fuel (coal, logs, planks, sticks, wooden tools) in
  the bottom slot; it glows and lights its surroundings while burning. Iron ore → iron ingot,
  sand → glass, cobblestone → stone, log → coal.
- **Chests**: 27 slots each, saved with the world; breaking a chest or furnace spills its contents.
- **Torches**: placed on top of solid blocks, they light the area with a warm point light and
  stop night creatures from spawning nearby.
- **Health**: ten hearts, fall damage, drowning (air bubbles while underwater) and slow
  regeneration. Dying drops your items where you fell; you respawn at the world spawn.
- **Night**: shadowy creatures spawn on unlit ground after dark, chase you and strike when
  close. They cannot break blocks, so walls and a roof keep you safe; they burn away at dawn
  and drop coal when defeated. Swords deal the most damage. They can be switched off in Settings.
- **Saving**: the seed, player position, time, inventory, tool wear, block edits, chest and
  furnace contents, dropped items and health are written when you pause, quit and every 30
  seconds after a change. **New World** on the title screen picks a fresh seed. The default
  seed (20261012) opens on a lakeshore clearing; for any seed the spawn search walks outward
  ring by ring (up to ~700 blocks) for a safe spot with an unobstructed view over water.

## Rendering overview

- **Geometry**: one storage buffer per chunk holding packed greedy quads; vertices are pulled in
  the vertex shader (`DrawProcedural`), so there are no per-block draws. Opaque and water
  meshes are separate, chunks outside the view frustum are skipped, and meshes are rebuilt only
  for chunks touched by edits (plus neighbours on borders). Positions are camera-relative.
- **Lighting**: GGX specular + Lambert diffuse with tangent-space normal maps from the
  material atlas, hemisphere sky ambient scaled by baked sky light and per-vertex AO, so caves
  and interiors go dark while open areas stay readable.
- **Shadows**: a sun (or moon) orthographic shadow map, stabilised by texel snapping, sampled
  with a rotated 12-tap Poisson disc for soft edges; size and distance follow the preset.
- **Sky**: analytic gradient with sunset warmth, sun disc and halo, moon, twinkling stars and an
  animated cloud layer; distance and height fog blends terrain into the sky at the render edge.
- **Water**: animated normal waves, Fresnel, screen-space reflections with sky fallback,
  depth-based absorption colour from the scene depth, refraction-style transparency and an
  underwater fog/tint when the camera is submerged.
- **Wind**: leaves sway as a canopy; grass and flowers bend at their tips with gusts.
- **Post**: HDR scene, bright-pass bloom (13-tap downsample, tent upsample, low strength),
  exposure that follows the time of day, ACES filmic tonemap, light vignette and dithering.

## Checks performed

- Built with `aqua build` for wasm, web and Windows targets; WGSL compiled by naga (desktop)
  and written to Tint's rules (uniform control flow, explicit-gradient sampling).
- Automated desktop test (`tools\build-test.cmd` swaps in `tools/debug/debug.aqua`): title →
  walk to a tree → hold-to-mine logs with cracks → drops and pickup → craft planks, a
  crafting table and sticks in the 2x2 grid → place the table → craft wooden and stone
  pickaxes, a furnace and torches in the 3x3 grid → place and fuel the furnace → mine with
  the stone pickaxe → place a torch at night → wait for night creatures → take damage. Each
  step logs the inventory and saves a screenshot (`build\cap-*.png`; `python tools/sheet.py`
  makes contact sheets).
- Automated language test (`tools/debug/lang.aqua`): title and settings in 繁體中文, switch to
  English and back, HUD message, item tooltips and recipe guide in both languages, pause and
  death screens.
- Web build served locally and played in a Chromium-based browser.
- `node --test` for the browser window/texture host modules.

## Known limitations

- Torch and furnace light is a per-pixel point light (up to 32 nearest sources) without
  occlusion, so it can shine through thin walls. Sky light comes from column heights and does
  not spread sideways into caves.
- Torches only stand on top of blocks (no wall torches); furnaces and chests face the player
  when placed but have no other block states.
- Water is static (no flowing or spreading); there is no lava, farming or hunger.
- Night creatures move straight toward the player (no path-finding) and burn in daylight
  even under a roof; there is one creature type.
- Chunk generation and meshing run on the main thread with a per-frame budget, so fast
  sprinting on the Low preset can briefly outrun streaming.
- Android hosting is not supported by the new WGPU window API yet.
- The browser build needs WebGPU; there is no WebGL fallback. Where a page may not lock the
  pointer (some embedded browsers), the game keeps running and looks with plain mouse motion,
  which stops at the window edge.
- Only characters already used in the game's strings are in the font atlas; new Chinese text
  shows `?` until `tools/gen_font.py` is re-run. The F3 debug overlay is translated but stays
  terse.
- `AquariusCore/runtime/LibraryCatalog.Generated.cs` was edited by hand for the new WGPU
  members because the catalog generator is out of date.
